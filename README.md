# РОЛЛЕВИЧ — сайт доставки роллов в Ижевске

Одностраничный сайт доставки японской кухни: тёмная премиальная тема
(графит, слоновая кость, шампань-золото, винный акцент), меню с категориями,
корзина и оформление заказа.

## Запуск

Боевой режим — вместе с сервером: `npm start` (см. раздел «Сервер»).
Посмотреть только витрину можно и без него: `python3 -m http.server 8000`.

## Меню

Полное меню образца (murakamicity.com): 22 раздела, 349 позиций — сеты, роллы,
горячие роллы, маки, спринг- и сладкие роллы, суши, гунканы, сашими, сэндвичи и
онигири, закуски и салаты, гёдза, бао, супы, рамэн, рис, вок, яки, поке, десерты,
напитки, соусы.

Что изменено при переносе:
- **Цены** выставлены в рублях под премиальную доставку Ижевска, отдельно по каждому
  разделу: Филадельфия 660–750 ₽, Калифорния 460 ₽, сет на 32 шт 1 650–2 500 ₽,
  вок 390–770 ₽, мисо 290 ₽, кола 0,5 л 150 ₽. Соотношение цен внутри разделов
  взято у образца. Перед запуском сверьте с себестоимостью по техкартам.
- **Составы** — со страницы образца, с исправленными опечатками. Где там был рекламный
  текст вместо состава, написан короткий состав. Фото и рекламные тексты не копировались.
- **Ролл «Мураками»** переименован в «Роллевич».
- **Пиво убрано** — дистанционная продажа алкоголя в России запрещена.
  Армянские вода и соки заменены на обычные позиции без бренда.
- **Вес не указан** — на сайте образца его нет. Добавьте в поле `meta`, например `"8 шт · 280 г"`.
- Метки «Хит» и «Новинка» — из подборок «Самое популярное» и «Новинки» образца.

## Как редактировать

- **Блюда и цены** — `assets/js/menu.js`. У каждого блюда: `name`, `desc` (состав), `meta` (количество), `price`, `tags` (`hit`, `new`, `spicy`, `kids`).
- **Фото блюд** — положите файл в `assets/img/menu/` с именем, равным `id` блюда
  (`philadelphia-with-avocado.webp`), и запустите `python3 tools/link_photos.py`.
  Фото заменит иллюстрацию. Список id — в `assets/js/menu.js`.

### Как снимать фото, чтобы карточки выглядели единообразно

- Квадрат 1:1, от 1000×1000 px, формат WebP, до 200 КБ.
- Ракурс 45° сверху-спереди, блюдо по центре и занимает около 70% кадра.
- Фон — тёмный графит или сланец, посуда — чёрная фактурная тарелка.
- В углу кадра имбирь и васаби, сзади не в фокусе соевый соус и палочки.
- Мягкий боковой свет с одной стороны, один и тот же для всех снимков.
- Роллы — 8 кусочков в два ряда срезом к камере; сеты — сверху на деревянной доске.
- **Доставка и промокоды** — `ROLLEVICH_CONFIG` в конце `menu.js`: стоимость доставки, порог бесплатной доставки, минимальный заказ, скидка за самовывоз, промокоды.
- **Цвета** — переменные в начале `style.css`.
- **Телефон, адрес, соцсети** — в `index.html` (сейчас стоят заглушки `+7 (3412) 00-00-00`, `hello@rollevich.ru`).

## CRM — окно заказов

`crm.html` — рабочее окно персонала. Заказ с сайта появляется в нём сразу после оформления,
обновлять страницу не нужно.

- **Заказы** — доска по статусам: Новые → Приняты → Готовятся → В пути → Выполнены.
  Кнопка на карточке переводит заказ дальше. Новый заказ подсвечивается и звенит (включите «Звук»).
  Заказ, который ждёт ответа дольше 5 минут, краснеет.
- **Карточка заказа** — клиент, телефон (кнопка «Копировать»), адрес, время, оплата,
  комментарий, состав, суммы, история статусов, отмена.
- **Новый заказ по телефону** — кнопка «+ Новый заказ». Администратор вводит телефон: если клиент уже
  заказывал, CRM подставит имя и адрес, покажет число заказов и любимое блюдо, а кнопка
  «Повторить последний» перенесёт прошлый заказ. Блюда выбираются из меню с поиском по названию
  (по началу слов: «фила авок» → «Филадельфия с авокадо»), сумма,
  скидки и доставка считаются сразу. Галочка «Клиент подтвердил» ставит заказ сразу в «Приняты».
  Администратору можно оформить заказ ниже минимальной суммы — CRM только предупредит.
  Такие заказы отмечены «Телефон», в истории видно, кто их принял, на кухню в Telegram
  они приходят с пометкой «Заказ по телефону». Повторить можно и из карточки любого заказа или клиента.
- **Архив** — все заказы с фильтром по статусу.
- **Клиенты** — собираются из заказов по телефону: число заказов, сумма, средний чек,
  любимое блюдо, адреса, метки «Новый» и «Постоянный».
- Сверху сводка за сегодня: заказы, выручка, средний чек, в работе, ждут ответа.

Где хранятся заказы (`assets/js/store.js` выбирает сам):
- **свой сервер** (`server/`) — боевой режим: база SQLite, вход для персонала, уведомления в Telegram;
- страница на claude.ai — общая база страницы, CRM открывается по ссылке сайта с `#crm`;
- файлы открыты без сервера — браузер (только для проверки).

## Касса и смены

Две вкладки CRM, работают на своём сервере.

**Касса** — учёт денег за смену кассира:
- кассир открывает смену и вводит, сколько наличных в кассе на начало;
- выручка считается сама — по заказам, выполненным за смену, отдельно наличные, карта курьеру и СБП;
- внесения и изъятия (размен, такси курьеру, закупка) с причиной и автором;
- при закрытии кассир вводит пересчитанные наличные, CRM сразу показывает недостачу или излишек;
- отчёт о закрытии сохраняется в «Прошлых сменах» и приходит в Telegram;
- в шапке CRM всегда видно: «Касса открыта · Мария» или «Касса закрыта».

Фискальная смена на онлайн-кассе (чеки, Z-отчёт по 54-ФЗ) открывается на самой кассе. Подключим её
к CRM после выбора оборудования (АТОЛ, Эвотор, облачная касса).

**Смены** — табель всех сотрудников:
- сотрудники отмечаются ПИН-кодом на планшете — страница `/smena`: ввёл ПИН — смена началась,
  ввёл ещё раз — закончилась. Пароль от CRM им не нужен;
- **в момент отметки планшет фотографирует сотрудника** — и на приходе, и на уходе. Фото видны в CRM
  у каждой смены, по нажатию открываются крупно. Если камера не сработала, отметка проходит,
  но в CRM у смены стоит «нет фото». Фото хранятся на сервере в `data/photos` и удаляются
  через 90 дней (`PHOTO_RETENTION_DAYS`);
- в CRM видно, кто сейчас на смене и сколько работает, обновляется само;
- табель за сегодня, вчера, неделю, месяц, прошлый месяц: смены и часы по каждому сотруднику;
- должности: повар, кухонный работник (заготовки), технический персонал (уборка), водитель-курьер,
  администратор;
- ставки и суммы к выплате, добавление сотрудников, смена ПИН, увольнение (ПИН перестаёт работать),
  закрытие забытых смен;
- планшет подключает администратор: открывает CRM на планшете → «Смены» →
  «Подключить этот планшет для отметок». Неподключённое устройство отметить смену не может.
- 5 неверных ПИН-кодов подряд блокируют планшет на 5 минут: подобрать чужой ПИН не получится.

**Кто входит в CRM.** Только администраторы — у них доступ к заказам, деньгам, кассе, табелю
и всем продажам. Повара, кухонные работники, технический персонал и курьеры в CRM не входят —
они только отмечаются на планшете. Администратор тоже отмечает свою смену на планшете.

**Фото сотрудников и закон.** Фото, по которому проверяют личность сотрудника, — это
биометрические персональные данные (152-ФЗ, ст. 11). До запуска возьмите с каждого сотрудника
письменное согласие на обработку фото и укажите эту обработку в положении о персональных данных.
Планшет предупреждает надписью «При отметке делается фото».

## Сервер

`server/` — Node.js 22.13+, без сторонних пакетов: база SQLite встроена в Node.

- Принимает заказы с сайта и **сам пересчитывает цены и скидки** по `menu.js`: подменить сумму из браузера нельзя.
- Номера заказов идут по порядку: 1001, 1002…
- Защита от спама: не больше 5 заказов с одного IP за 10 минут и 10 с одного телефона за час,
  скрытое поле-ловушка для ботов.
- CRM доступна только сотрудникам: логин и пароль, пароли хранятся в виде хэша (scrypt),
  сессия на 30 дней в защищённой cookie. Не больше 10 попыток входа за 15 минут.
- Новые заказы и смена статусов приходят в открытые окна CRM сразу (Server-Sent Events).
- Наружу отдаются только файлы сайта — `server/`, `data/` и `.env` недоступны.

### Уведомления в Telegram

Каждый новый заказ приходит сообщением в чат: номер, клиент, телефон, адрес, состав, сумма.
Под сообщением кнопки «Принять →», «На кухню →», «Передать курьеру →», «Выполнен →» и «Отменить» —
они меняют статус в CRM, а в истории заказа видно, кто нажал. Если статус поменяли в CRM,
сообщение в Telegram обновляется само. Кнопки работают только в подключённых чатах.

Как подключить:
1. В Telegram откройте **@BotFather**, отправьте `/newbot`, задайте имя (например, «РОЛЛЕВИЧ Заказы»)
   и получите токен вида `123456:ABC...`.
2. Создайте группу для заказов (администраторы, кухня), добавьте в неё бота.
3. Впишите токен в `.env` (`TELEGRAM_BOT_TOKEN=...`) и перезапустите сервер.
4. Напишите в группе `/id` — бот ответит ID чата. Впишите его в `TELEGRAM_CHAT_IDS`
   (несколько чатов — через запятую) и снова перезапустите сервер.

### Установка на VPS

Нужен VPS в России (персональные данные клиентов по 152-ФЗ хранятся в РФ): Timeweb Cloud,
Selectel, REG.RU и т. п. Хватит самого простого тарифа — 1 ядро, 1 ГБ памяти, Ubuntu 24.04.
Домен (например, rollevich.ru) направьте A-записью на IP сервера.

```bash
# 1. Node.js 22 и nginx
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs nginx certbot python3-certbot-nginx git

# 2. Код и пользователь, от которого работает сервер
sudo useradd --system --home /opt/rollevich rollevich
sudo git clone https://github.com/aniartem/blem.git /opt/rollevich
sudo mkdir -p /opt/rollevich/data && sudo chown -R rollevich /opt/rollevich

# 3. Настройки: адрес сайта, токен Telegram
sudo -u rollevich cp /opt/rollevich/.env.example /opt/rollevich/.env
sudo -u rollevich nano /opt/rollevich/.env

# 4. Первый сотрудник (пароль спросит)
cd /opt/rollevich && sudo -u rollevich npm run user:add -- admin "Администратор"

# 5. Автозапуск, HTTPS, ночные копии базы
sudo cp deploy/rollevich.service /etc/systemd/system/ && sudo systemctl daemon-reload
sudo systemctl enable --now rollevich
sudo cp deploy/nginx.conf /etc/nginx/sites-available/rollevich   # впишите свой домен
sudo ln -s /etc/nginx/sites-available/rollevich /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d rollevich.ru -d www.rollevich.ru
sudo cp deploy/backup.cron /etc/cron.d/rollevich-backup
```

Сайт — `https://rollevich.ru`, CRM — `https://rollevich.ru/crm`, терминал смен — `https://rollevich.ru/smena`.

Повседневные команды (из `/opt/rollevich`, от пользователя `rollevich`):

| Что сделать | Команда |
|---|---|
| Добавить администратора CRM | `npm run user:add -- anna "Анна"` |
| Сменить пароль | `npm run user:passwd -- maria` |
| Удалить сотрудника | `npm run user:remove -- maria` |
| Список сотрудников | `npm run users` |
| Копия базы вручную | `npm run backup` |
| Обновить сайт | `git pull && sudo systemctl restart rollevich` |
| Журнал сервера | `sudo journalctl -u rollevich -f` |

Изменения в `menu.js` (цены, блюда) сервер подхватывает сам в течение 5 секунд.

Проверки сервера: `npm test`. В них заказ, цены, ошибки формы, защита от спама, вход,
права, живые обновления и Telegram (на поддельном API, без настоящего бота).

## Что нужно доделать перед запуском

1. **Сервер.** Арендовать VPS и домен, установить по инструкции выше, подключить Telegram-бота. При желании — передача заказов в iiko / r_keeper / Frontpad.
2. **Онлайн-оплата** — ЮKassa, CloudPayments или Тинькофф Касса.
3. **Реальные фотографии** блюд.
4. **Зоны доставки** — уточнить районы, время и минимальные суммы, по возможности добавить карту (Яндекс.Карты).
5. **Юридическое**: политика конфиденциальности, согласие на обработку персональных данных (152-ФЗ), реквизиты ИП/ООО в подвале.
